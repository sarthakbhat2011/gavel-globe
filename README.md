# 🏛️ Gavel & Globe — Model UN Guide & Delegate Toolkit

> A comprehensive Model United Nations learning platform and live speechcraft toolkit built specifically for the Indian and international collegiate MUN circuits.

---

## ✨ Features

- **The Foyer:** Interactive overview of Model UN dynamics, committee anatomy, and procedure fundamentals.
- **MUN 101 & Rules of Procedure:** Stage-by-stage guide covering the General Speakers List (GSL), Moderated/Unmoderated Caucuses, Points & Motions, and Resolution drafting.
- **The Indian Circuit:** Specialized cheat-sheet on AIPPM/Lok Sabha, Executive Board expectations, chit-passing etiquette, and hybrid procedure.
- **The Delegate Toolkit:**
  - 🎙️ **Speech Architect:** Dynamic GSL, caucus speech, and right-of-reply generator with adjustable rhetoric levels.
  - 🎯 **Question Forge:** High-impact Points of Information (POIs) and challenge question generator.
  - 💬 **Comment Composer:** Structured rebuttal and diplomatic intervention builder.
  - 📜 **Motion Cheat Sheet:** Searchable motions library with verbatim phrasing.
  - 🌐 **Bloc Generator:** Creative multilateral coalition name generator.
- **The Trial:** Interactive 10-question MUN aptitude and procedure quiz with instant verdict certification.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **UI & Styling:** Tailwind CSS v4, Radix UI (shadcn/ui), Lucide Icons
- **Animation:** Framer Motion
- **Language:** TypeScript
- **State Management:** Zustand, React Hooks

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v20 or higher) or [Bun](https://bun.sh/)
- npm, pnpm, yarn, or bun

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/gavel.git
   cd gavel
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🐳 Docker

To run with Docker:

```bash
docker compose up --build -d
```
Visit [http://localhost:3000](http://localhost:3000).
